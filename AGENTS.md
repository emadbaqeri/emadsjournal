# emadsjournal

Astro + TypeScript, CSS Modules and design tokens. No Tailwind, no UI framework at scaffold time. Working notes: `docs/agent/plan.md` and `docs/agent/progress.md`.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

Regenerate design tokens after updating `src/tokens/tokens.json`:

```
npm run tokens
```

Commit both `tokens.json` and the generated `src/tokens/tokens.css`.
