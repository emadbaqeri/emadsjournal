## Intuition

Walk the matches once. For each result, add 3 points to the winner and, if they just passed the current leader, they become the leader. The TypeScript and Rust versions use a hash map (O(n) time, O(k) space). The C snapshot uses parallel arrays and a linear search instead, which is O(n·k) time.
