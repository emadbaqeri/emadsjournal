## Intuition

Brute force tries every pair. The hash-set walk asks, at each number, whether `target - x` is already in a set of numbers you have seen; if not, you store `x` and keep going. Sorting a copy and closing in with two pointers is slower than the set, but it needs no extra lookup structure beyond the sorted copy.

## Common traps

<CommonTraps
  wrong="Start the inner loop at j = 0. A number can pair with itself, and every pair is checked twice."
  right="Start the inner loop at j = i + 1 so each pair is used once, and never the same index twice."
/>

<CommonTraps
  wrong="In JS/TS, sort the numbers with plain .sort(). It compares them as strings, so -1 and 11 land in the wrong order."
  right="Sort numerically: [...list].sort((a, b) => a - b). Then the two pointers walk a real number line."
/>
